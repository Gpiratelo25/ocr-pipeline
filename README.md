# ocr-pipeline

Projeto

Objetivo deste projeto é de extrair dados de emenda de contratos, e montar uma tabela geral com esses dados e prover análises de mudanças e variações

link para conseguir os contratos:
https://mcc.law.stanford.edu/search#download


Definições claras do que será extraido
Party: Definição de empresa ou organização que participa do acordo

date= qualquer data relevante mencionada no texto
agreement= nome ou tipo de instrumento juridico
section= referente a clausula
